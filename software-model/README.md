# Proyecto de Arquitectura de Computadores II

**Autores:** Sebastián Hidalgo, Jessica Espinoza, Estefanny Villalta

Este proyecto implementa un arreglo sistólico para la aceleración de operaciones matriciales, como parte del curso **Arquitectura de Computadores II**.

## Instrucciones de Ejecución

1. Navegar al directorio donde se encuentra el archivo `Makefile`.
2. Ejecutar el siguiente comando para limpiar archivos generados previamente:

   ```bash
   make clean

3. Compilar el proyecto con 


   ```bash
   make
4. Ejecutar el proyecto con 
   ```bash
   make run
